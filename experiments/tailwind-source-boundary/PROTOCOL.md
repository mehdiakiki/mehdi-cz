# PERF-050 preregistered protocol

Purpose: isolate the remaining shared Tailwind CSS gate after PERF-049. This
research supports a reference devoted to web performance; there are no career,
portfolio, or general Next.js tutorial claims.

1. Inspect source discovery before using runtime coverage to delete CSS. Compare
   the retained 89,482-byte production artifact, a fresh automatic scan, and the
   same compiler/configuration with automatic discovery disabled. Trace removed
   rules to their source candidates. Preserve all explicitly configured sources.
2. Add a unique valid utility to a non-application text fixture. It must alter
   automatic output and leave explicitly bounded output identical. Also prove
   that a real configured component source still affects bounded output. This
   establishes causality independently of a screenshot or a coverage percentage.
3. If a deterministic byte reduction exists, isolate only stylesheet delivery
   with the same Next production build behind matched HTTP proxies. Keep content,
   scripts, fonts, caching, compression, resource order, and request count fixed.
4. Measure fresh-context initial loads across home, writing index, prose article,
   code article, and Atlas. Alternate treatment order within route/repetition;
   retain individual samples, paired differences, bootstrap intervals, and wins.
   Use mobile Slow 4G / 4x CPU, plus an independent desktop or network profile.
5. Validate mobile/desktop, light/dark, opened search, menu, scrolled content,
   no-JavaScript rendering, hard-navigation reuse, and soft navigation. Compare
   exact sampled pixels and computed styles. Any new layout shift, exception,
   missing style, or behavior failure blocks retention until resolved.
6. Coverage is a state-dependent diagnostic, never a proof of dead code. Record
   initial, scrolled, and interactive states separately. Do not claim a field
   Core Web Vitals improvement from lab runs.
7. If source bounding works, apply the smallest source correction and validate
   a fresh production artifact. Re-evaluate route splitting against that smaller
   baseline rather than attributing a source-discovery fix to a framework feature.

Baseline: `.next-perf049`, Next 16.3.4, Tailwind 4.3.3. Original CSS and all new
raw evidence live under this experiment. Timing samples must not overlap builds
or coverage collection. Exploratory choices and failed tests remain documented.
