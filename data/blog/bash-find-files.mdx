Find files by name:

```bash
find . -name "*.log"
```

Find and delete empty files:

```bash
find . -type f -empty -delete
```

Run a command safely for each matching file:

```bash
find . -type f -name "*.log" -exec printf '%s\n' {} \;
```

Use `-print0` with an option such as `xargs -0` when passing paths to a second command in bulk.
