summary: "Use curl to download or interact with HTTP endpoints."
---

Basic GET:

```bash
curl -sS https://example.com
```

Download to a file:

```bash
curl -sS -o page.html https://example.com
```

Show response headers without downloading the response body:

```bash
curl -I https://example.com
```

Use `-L` when the request should follow redirects.
