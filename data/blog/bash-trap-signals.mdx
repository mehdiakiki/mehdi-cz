summary: "Use trap to run cleanup on EXIT or signals."
---

Create the temporary file before registering the cleanup handler:

```bash
tmpfile=$(mktemp)
trap 'rm -f "$tmpfile"' EXIT
```

Use a function when cleanup needs more than one command:

```bash
cleanup() {
  rm -f "$tmpfile"
}

trap cleanup EXIT INT TERM
```
