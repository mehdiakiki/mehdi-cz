summary: "Use cp to copy files and directories."
---

Copy a file:

```bash
cp src.txt dest.txt
```

Copy a directory recursively:

```bash
cp -r srcdir/ destdir/
```

Use archive mode when permissions, timestamps, symbolic links, and other attributes must be
preserved:

```bash
cp -a source.txt dest_dir/
```

Use `cp -i` to ask before overwriting an existing destination.
